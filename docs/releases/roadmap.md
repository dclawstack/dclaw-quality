# Roadmap

## v1.4 — Detail Views & Polish (Q2 2026)

- [ ] Detail pages: `/batches/{id}`, `/inspections/{id}`, `/defects/{id}`
- [ ] Inline relationship views (batch → inspections, inspection → defects)
- [ ] Pagination on all list tables
- [ ] Sortable columns in data tables
- [ ] Date-range filtering for inspections

## v1.5 — Advanced Analytics (Q3 2026)

- [ ] Statistical Process Control (SPC) charts — control limits, Cp/Cpk
- [ ] Trend analysis over time (pass/fail rates by month)
- [ ] Export to CSV / PDF for audit compliance

## v1.6 — AI & Workflow (Q4 2026)

- [ ] LLM-powered inspection summaries via Ollama / OpenRouter
- [ ] CAPA (Corrective / Preventive Action) workflow engine
- [ ] Supplier Quality Management module (scorecards, PPM tracking)
- [ ] Document / photo upload for inspection evidence

## Long Term (2027+)

- [ ] Real-time collaboration & notifications
- [ ] Mobile-responsive PWA
- [ ] SSO / SAML integration
- [ ] Third-party ERP connectors (SAP, NetSuite)
- [ ] White-label customization
