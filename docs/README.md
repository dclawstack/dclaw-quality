# DClaw Quality

> **AI-powered Quality Management System for manufacturing teams.**

**Category:** Manufacturing  
**Version:** 1.3.0  
**Status:** Active Development (MVP Ready)

## Overview

DClaw Quality is a modern, lightweight QMS (Quality Management System) built for mid-market manufacturers. It replaces expensive enterprise suites ($50K+/year) and fragile spreadsheet workflows with a real-time platform that works in days — not quarters.

### Key Capabilities

- **Product → Batch → Inspection → Defect** traceability chain
- **Real-time Dashboard** with pass rates, defect severity breakdowns, and trend summaries
- **AI Defect Classification** — describe a defect in plain English and get auto-classified type, severity, and recommended corrective action
- **Full REST API** with typed CRUD for all domain entities
- **Docker-first** deployment with zero-config local development
