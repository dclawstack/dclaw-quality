# API Reference

## Base URL

```
http://localhost:8047/api/v1
```

## OpenAPI Docs

Interactive docs are auto-generated by FastAPI:

```
http://localhost:8047/docs
```

## Endpoints

### Health

```http
GET /health/
```

**Response:**
```json
{"status":"ok"}
```

### Products

```http
GET    /api/v1/products          # list (query: skip, limit, search)
POST   /api/v1/products          # create
GET    /api/v1/products/{id}    # retrieve
PUT    /api/v1/products/{id}    # update
DELETE /api/v1/products/{id}    # delete
```

### Batches

```http
GET    /api/v1/batches          # list (query: skip, limit, product_id, status)
POST   /api/v1/batches          # create
GET    /api/v1/batches/{id}     # retrieve
PUT    /api/v1/batches/{id}     # update
DELETE /api/v1/batches/{id}     # delete
```

### Inspections

```http
GET    /api/v1/inspections      # list (query: skip, limit, batch_id, result)
POST   /api/v1/inspections      # create
GET    /api/v1/inspections/{id} # retrieve
PUT    /api/v1/inspections/{id} # update
DELETE /api/v1/inspections/{id} # delete
```

### Defects

```http
GET    /api/v1/defects          # list (query: skip, limit, inspection_id, severity, defect_type)
POST   /api/v1/defects          # create
GET    /api/v1/defects/{id}     # retrieve
PUT    /api/v1/defects/{id}     # update
DELETE /api/v1/defects/{id}     # delete
```

## Error Handling

Standard FastAPI HTTPException responses:

| Code | Meaning |
|------|---------|
| `400` | Bad request / validation error |
| `404` | Resource not found |
| `409` | Conflict (e.g., duplicate SKU) |
| `422` | Pydantic validation failure |
