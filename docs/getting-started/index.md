# Getting Started with DClaw Quality

Welcome to DClaw Quality. This guide will help you install, configure, and start using the app.

## What is DClaw Quality?

DClaw Quality is an AI-assisted quality management system for manufacturing teams. It tracks:

- **Products** — your catalog with SKU, category, and lifecycle status
- **Batches** — production runs linked to products with quantity and status
- **Inspections** — QA checks performed on batches with pass/fail/pending results
- **Defects** — issues logged during inspections, with AI-powered classification

The built-in dashboard aggregates everything into real-time KPIs: inspection counts, pass rates, defect severity trends, and batch status distribution.

## Prerequisites

- Docker & Docker Compose (for local development)
- Node.js 20+ and Python 3.11+ (for native development)
- PostgreSQL 16 (Docker will provision this automatically)
